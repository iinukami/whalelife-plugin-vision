# WhaleLife 视听理解插件

0.5.0 包含可选的本机 Ollama 视觉描述，适用于图片、视频和按需看屏，插件 ID 仍为 `vision`。来源插件取得媒体，本插件准备画面和声音证据，当前聊天的主模型据此理解；不提供长期收藏、常驻监听或平台外发。视频只需一个 `media_understand` 调用，即可按同一来源时间范围看画面、读转写或分析音乐。

默认由当前主模型接收原生图片；选择本地 Ollama 描述后，**原图只交给本机视觉模型，主模型只收到文字证据**。两种方式都不将原始音频交给主模型；声音按用途调用明确配置的本地或云端后端。不会暗中切换主模型或在失败时改用另一后端。

## 使用

首次安装或交给 agent 安装时，先看 [FFmpeg 获取与安装说明](vendor/FFMPEG-INSTALL.md)：包含上游下载地址、源码准备命令、已有插件目录的手动安装位置和校验步骤。FFmpeg 是第三方媒体解码组件；源码安装由用户本机从上游获取，语音模型另行准备。

设置页分别显示视觉与听觉能力；未准备语音资源不影响看图。视觉提供画质、独立画面／拼图、自动变化细节、画面预算与采样密度；声音保留原有按用途选择的本地／云端后端。点击“保存并生效”会保存并应用本插件设置，核对运行版本后才提示成功；未保存、应用中、已保存待生效和应用失败分别显示。应用设置会结束当前视听任务及声音资源下载，不中断独立的 Ollama 准备，使临时媒体引用失效，已安装的声音资源保留。失败时可重试“应用已保存设置”；单纯打开插件管理不会执行重载。宿主支持图片接口、云端模型已选择，都不代表所选提供商已通过兼容性测试。

1. 在插件设置中选择语音与音乐用途的本地/云端后端；默认均为本地。使用云端时，另选对应类型的模型连接。
2. 需要本地语音时，点击“一键准备本地能力”。只有此按钮发起下载；安装插件、启动、工具调用都不会静默下载。
3. 来源插件通过已声明的可选服务交入当前会话的媒体字节，取得短期引用；主模型使用 `media_understand`。图片默认看图；有声音的视频/音频默认转写。音乐分析和复杂声音理解须显式请求，避免每段都跑全部任务。

默认每次处理 30 秒，最多 60 秒；源视频/音频最长 60 分钟，仍受单媒体容量限制。可以分段补看、补听；没有下一段不表示此前所有片段都已处理。只看指定视频时刻时不默认处理声音。旧 `vision_view` 和 `prepare()` 保持纯视觉行为，包括 `audioIncluded:false`。

## 视觉与看屏

“画面理解方式”可选择主模型直接看图，或本地 Ollama 描述。选择本地方式可减少主模型的图片输入，文字描述及日常聊天仍有文本用量；小模型可能漏看、误读或无法回答细节问题。三个视觉工具统一遵循用户保存的方式，AI 不能用工具参数改为更贵的后端。本地调用失败只报告问题，保留可用的声音结果，不自动上传原图、下载或启动模型。下载与启动仅由用户在设置页明确点击。

本地配置可以选择两种来源，切换时保留原模型连接选项：

### 一键准备的小模型（Windows x64）

1. 在“本地 Ollama 描述”中，将来源选为“插件准备的固定小模型”，点击“一键准备并启动”。插件从官方固定版本地址下载 Ollama 0.40.16，校验大小与 SHA-256 后解压；随后通过 Ollama 官方模型库准备固定的 `qwen3-vl:2b`。组件约 1.62 GB、模型约 1.9 GB，还需解压与临时空间，页面显示实际进度。
2. 准备需要时会打开可见的“WhaleLife - Local Ollama”CMD 控制台，完成后保持运行。只有“已启动”且“模型已就绪”才可用；这仍不是复杂画面理解质量的保证。点击“保存并生效”应用来源选择，无须改日常主模型或另配宿主模型连接。
3. 下次可点击“启动 Ollama”；“停止 Ollama”只关闭插件拥有的服务，下载文件保留。启动不自动下载缺失模型，需明确点击准备；插件停用会结束其自有服务，普通设置保存不会中断 Ollama 准备任务。
4. 若已有默认本机服务运行，显式检测/准备可以复用其中的固定模型，避免重复下载。已有服务不会被插件接管或停止；未在运行的任意安装目录不会被自动扫描。接入任意已有模型继续使用下面的宿主模型连接方式。

插件自有组件和模型存放于 `data/ollama/`，自有服务只监听 `127.0.0.1:11435`；已有默认服务为 `127.0.0.1:11434`。状态读取不下载、不启动、不推理，检测只读取本机服务/模型元数据。“取消”中止本次准备请求；其他客户端共享的模型下载可能仍在继续。取消后可重试，完整模型由 Ollama 校验。未经校验或不支持视觉/报告远端的模型不会作为就绪结果。

官方获取入口：[Ollama Windows](https://ollama.com/download/windows)、[固定组件及摘要](vendor/ollama.json)、[模型页面](https://ollama.com/library/qwen3-vl:2b)。插件发行包不携带 Ollama 二进制或视觉模型。组件目录被改动或校验失败时拒绝启动；无法识别的旧目录不会被自动覆盖。

### 使用已有宿主模型连接

手动配置步骤：

1. 从 [Ollama 官方 Windows 指南](https://docs.ollama.com/windows) 安装并启动 Ollama。用户自行下载支持视觉的本地模型，例如运行 `ollama pull qwen3-vl:2b`；[该模型官方页面](https://ollama.com/library/qwen3-vl:2b)列有视觉能力和版本要求。模型文件大小不等于运行内存，本插件不承诺特定机器的速度。
2. 在 WhaleLife 的模型服务设置添加 OpenAI 兼容连接，地址 `http://127.0.0.1:11434/v1`，关闭代理；本机 Ollama 的 API Key 可留空（若界面要求填写，用示例值 `ollama`）。添加类型为对话或自定义的模型条目，实际模型名填写已下载的名称，如 `qwen3-vl:2b`。不要更换日常聊天的主模型。
3. 在视听设置选择“本地 Ollama 描述”，选中刚才的模型条目，保存并生效。默认描述预算 512 token，可设 128–1024；可先将画面预算设为 2–4、画质设为概览，再按实测调整。减少帧数仍保留时段首尾，但可能遗漏中间细节。

只接受本机回环地址及明确选定的模型连接；调用前检查 Ollama 模型具有视觉能力并拒绝云端模型。按 [Ollama 视觉 API](https://docs.ollama.com/capabilities/vision)将当前图片和有限的观察问题送入本地模型，不发送整段聊天、人格或记忆。模型回复有容量和时限上限，一次只运行一个本地视觉任务，请求固定传入 `think:false` 以减少思考开销，但仍取决于模型支持，预算过低可能没有最终描述；只读取最终正文。生成预算用尽时标明截断；请求断开不代表 Ollama 服务立即释放所有显存，服务及权重由用户自行管理。配置和状态读取不探测模型或产生推理。

视觉默认保持原有行为：自动画质（概览 640、指定时刻细看 1600 最大边）、独立画面、全景、最多 8 个画面、每秒检查 2 次。可选择更清晰的画质或更密的采样；增加画面与像素通常增加处理量及主模型图片用量。本次工具的显式参数优先于设置默认值。

“全景＋变化细节”适用于视频和动图：先检查整个所选时间段，再在有可靠局部变化时附加一张细节图，保留首尾全景。局部图标出来源时刻和裁剪范围，不把变化程度当作内容重要性。静态图片、单独时刻、变化分散或预算不足时保留全图；手动 `crop` 优先。所有图片保持比例，细节图也计入画面预算，最多 8 个画面。拼图适合概览，小字可再用单独时刻和裁剪补看。

看屏默认为关闭。在“按需看屏”启用并点击“保存并生效”后，AI 可自主调用 `screen_view`：

- `mode:snapshot` 查看现在；`mode:observe` 从现在开始观察 2–60 秒，默认 10 秒。不能回看调用前发生的画面，也不采集声音。
- `target:window` 固定采集开始时的前台窗口，逐帧更新其位置；只能看到屏幕上可见的窗口区域，遮挡内容不可见。`target:screen` 查看主屏幕。工具显式选择优先于默认设置。
- 调用时才启动 Windows 自带的采集进程；采集本身不需要 Python 或额外模型，选择本地理解时另需用户准备 Ollama。初始化和设置页刷新不抓屏，不保存截图文件，不复用上一次画面。一次只运行一个看屏任务，取消或停用时结束采集。
- 看屏返回带真实采样时间的独立图片，完整观察请求时段后再取舍，不因帧数达到上限提前结束。视觉拼图和视频变化细节设置不改变看屏输出；窗口目标可用于聚焦可见窗口。

主模型直接看图模式下，截图发送给当前主模型的提供商；本地描述模式下，只有描述文字交给主模型。工具资料沿用临时输入规则，普通最终回答及用户显式启用的宿主诊断记录按宿主规则保留；本地模式不向宿主提供截图，但描述仍可能包含画面文字。画面和描述中的指令只是资料，不授予操作权限。看屏当前只支持 Windows；无法采集、窗口关闭或最小化时明确失败。

| 用途 | 本地能力 | 云端能力与限制 |
| --- | --- | --- |
| speech 语音 | SenseVoiceSmall q8 + FSMN-VAD，输出转写和语音活动分段时间；不是逐字对齐 | 选定 STT 连接；仅采用提供商实际返回且通过范围校验的分段时间 |
| sound 复杂声音 | 不提供完整环境声理解；语音附带事件标签只作有限预测 | 选定音频理解连接，对片段作文字描述；不是精确事件量测 |
| rhythm 节奏 | 能量起音/自相关估计 BPM 候选，可能半拍/倍拍；无拍号或强拍保证 | 片段描述，不能当作精确 BPM 测量 |
| melody 旋律 | 混合音频的主导周期音高候选；无声部分离，不等于主唱旋律或乐谱 | 片段描述，不能当作逐音符转录 |
| chords 和弦 | 24 个大/小三和弦模板候选；分数不是概率，不识别全部和弦类型 | 片段描述，不能当作准确和弦谱 |
| structure 结构 | 片段内能量/色度变化点；不能据短片段标整首歌的主歌、副歌 | 片段描述，不能证明未提供部分的整曲结构 |

本地音乐分析为有界 TypeScript 算法，不需要 Python、Torch、分离模型或音乐权重。证据不足会明确返回不足；本地语音空结果也不能证明片段没有声音。

## 配置和资源

语音云端连接必须为 `stt` 类型、`openai-compatible` 协议，使用 `/audio/transcriptions`。声音/音乐理解连接必须为 `chat` 或 `custom` 类型、同一协议，并由提供商实际支持当前实现的 Qwen-Omni 兼容 `input_audio` WAV 输入、SSE 与文字输出。选择“兼容协议”或模型名字本身不证明它支持音频。配置只保存连接 ID；凭据仍由宿主管理。云端模式会把所选片段交给该提供商，未配置或不兼容时明确失败，不回退本地。

本地语音当前限定 Windows x64 CPU。固定公开资源共 **260,887,284 字节**（约 248.8 MiB 下载量，另需解压及临时空间），CPU 固定 8 线程，本地任务单次串行。资源版本、实际大小和 SHA-256 固定在 [vendor/sensevoice.json](vendor/sensevoice.json)，没有任意命令、路径或下载 URL 配置。设置页显示就绪状态、下载进度及失败说明；重复准备合并，校验后原子安装，失败可重试。停用取消下载与在途任务。2026-11-08 的授权本机验收中，13.7 秒合成中文语音的解码与本地转写合计约 3.9 秒；有同音字误转，这一单样本不代表任意录音的速度或准确率。

资源直连不可达时，可在“资源下载代理”填入已配置的 HTTP/HTTPS 代理地址（不含用户名密码），保存并生效后再准备。只改变本地语音资源下载路由，不用于 Ollama 下载，官方地址与摘要校验不变；不修改模型连接或自动直连重试。留空表示直连，Windows 系统代理开关不会自动成为此设置。

视频与音频解码使用插件目录内固定的 FFmpeg/ffprobe 9.0.2，不依赖系统 PATH。源码构建会准备并复制这些组件；已有安装缺失或损坏时，按 [安装说明](vendor/FFMPEG-INSTALL.md) 补齐并重载。启动校验失败时关闭相应解码能力；图片/GIF 不依赖这些程序。设置修改后点击“保存并生效”，原有容量和有效期配置保留，旧自定义解码器路径继续忽略。

## 媒体、时间与隐私边界

- 图片支持 JPEG、静态 PNG、WebP、GIF；单图 25 MiB、4000 万像素，动画最多 2000 帧，APNG 拒绝。视频支持有限 MP4/WebM；音频接受经内容核验的 WAV、MP3、FLAC、Ogg、音频 MP4/WebM。
- 视觉默认按 2 fps 低分辨率网格选变化帧与兜底帧，可选 1／2／4／6 fps；画面预算为 2–8，首尾与全时间段覆盖优先。支持指定时刻、归一化局部裁剪、自动变化细节、独立图片或拼图。概览长边最多 640，细节最多 1600；图片去除 EXIF。采样可能遗漏快速动作，`timelineComplete:false` 不表示完整观看。
- 画面、音频覆盖范围和证据顶层 `segments` 使用源媒体秒数。音乐 `details.timeOrigin:"clip_start"` 内的音符、和弦、变化点等时间，以及云端分析正文中的时间，均以本次片段起点为零；不要再次偏移顶层分段或把内部特征当作源时间。
- 默认单媒体 64 MiB、总暂存 256 MiB，引用 30 分钟有效；每会话最多 16 份、全局 64 份，同时服务调用最多 2 项。引用只对交入时固定的会话有效，应用新设置或重载后不恢复。图像与音频共同读取同一原始暂存媒体；解码片段只短期存在。
- 原始媒体位于插件自己的 `data/media/`；语音资源位于 `data/audio-local/`。正常结束、失败或取消后清理识别片段；启动/准备检查并清理确切自有命名的孤儿片段，不删除未知文件或跟随符号链接。资源模型保留供下次使用。
- 工具资料与后续复制的临时参数按宿主临时工具契约隔离，不把 base64、原声、引用、完整转写写进动作回执。**普通会话的最终回答仍按宿主规则持久化**，其中可能包含模型引用的媒体内容；临时输入不等于最终回答完全不留存。技术性 transient 执行入口另有宿主规则。
- 取消、过期、释放与停用会停止或丢弃在途结果；不会把失败伪装成已理解。声音或画面单项失败可返回明确的部分结果。来源资料是证据，不是指令或操作授权。

本版仅通过显式启用的按需看屏访问桌面，不直接访问网页、QQ 或摄像头。真实网页视频取得方式及来源插件接入由各自维护方实现；本轮没有修改浏览插件。跨插件方法与具体返回值见 [CONTRACT.md](CONTRACT.md)，公共协作事项见 [CORE-REQUEST.md](CORE-REQUEST.md)。

## 开发、验证和发行

使用 Node.js 24.22.1 或更新版本，宿主源码置于同级 `../whalelife`。生产插件只使用宿主公开 API。构建首次准备固定 FFmpeg 资源，校验后缓存到忽略的 `runtime/` 并复制进发行包；已验证缓存可离线构建。此构建步骤不会准备 SenseVoice 权重。

```sh
npm ci --ignore-scripts
npm run check
npm run build
npm test
```

0.5.0 最终通过 298 项隔离回归（含显式启用的 Windows 可见窗口专项），包含一键准备、停止/关闭窗口后重启、取消与清理失败、设置生效及新旧宿主兼容。已在本机验证准备、启停和合成图片理解；本轮复用已校验资源，没有重新完整下载大包。0.4.1 另完成一次 Windows CPU 上的真实 Ollama 合成图片／短视频验收；三个结果为纯文字，数字、颜色与顺序正确。首次看图约 30 秒，同图连续再看约 12 秒，两帧视频约 58 秒，仅代表该样本和机器。真实桌面采集、复杂自然画面与长视频仍未验收。0.2.0 的正式音频验收是历史记录；当前安装以实际运行版本为准，完整范围和限制见源码仓库 `VALIDATION.md`。

普通 `npm run build` 只生成本地测试包，并在 `RELEASE-STATUS.json` 标记为未经二进制发布验收。公开含 FFmpeg 的安装包前，必须完成 [源码材料审查](vendor/FFMPEG-SOURCE-REVIEW.md)，执行 `npm run build:release`，上传前再执行 `npm run release:check`。检查仅离线读取资料，不下载、不联系服务；资料不齐时会失败，并保留既有产物。当前固定 Gyan 构建的完整材料仍待取得，不把类型检查或业务测试通过当作发布许可。

发行目录为 `dist/vision/`，包含生产依赖、视频组件、许可与 `BUILD.json` SHA-256 清单，不包含用户数据或本地语音权重。安装目录仍为宿主 `plugins/vision/`，升级保留自己的 data。开发会话只完成本地验证与提交；推送和 Release 交统一发布会话。
