# WhaleLife 视听理解插件

0.2.0 在现有视觉插件中加入听觉理解，插件 ID 仍为 `vision`。来源插件取得媒体，本插件准备画面和声音证据，当前聊天的主模型据此理解；不提供长期收藏、主动监听或外发。视频只需一个 `media_understand` 调用，即可按同一来源时间范围看画面、读转写或分析音乐。

当前主模型收到的是**原生图片与文字证据，不是原始音频**。图片沿用当前主模型；声音按用途调用明确配置的本地或云端后端。不会暗中切换主模型或在失败时改用另一后端。

## 使用

首次安装或交给 agent 安装时，先看 [FFmpeg 获取与安装说明](vendor/FFMPEG-INSTALL.md)：包含上游下载地址、源码准备命令、已有插件目录的手动安装位置和校验步骤。FFmpeg 是第三方媒体解码组件；源码安装由用户本机从上游获取，语音模型另行准备。

设置页首先显示实际运行中的语音、音乐和环境声能力；本地资源就绪时无需额外配置。处理方式、可选云端连接、下载详情和高级容量限制可按需展开。隐藏的模型选择仍保留；修改、保存待重载和已生效分别提示，保存后可前往插件管理重载。云端模型已选择不代表兼容性或连接已通过测试。

1. 在插件设置中选择语音与音乐用途的本地/云端后端；默认均为本地。使用云端时，另选对应类型的模型连接。
2. 需要本地语音时，点击“一键准备本地能力”。只有此按钮发起下载；安装插件、启动、工具调用都不会静默下载。
3. 来源插件通过已声明的可选服务交入当前会话的媒体字节，取得短期引用；主模型使用 `media_understand`。图片默认看图；有声音的视频/音频默认转写。音乐分析和复杂声音理解须显式请求，避免每段都跑全部任务。

默认每次处理 30 秒，最多 60 秒；源视频/音频最长 60 分钟，仍受单媒体容量限制。可以分段补看、补听；没有下一段不表示此前所有片段都已处理。只看指定视频时刻时不默认处理声音。旧 `vision_view` 和 `prepare()` 保持纯视觉行为，包括 `audioIncluded:false`。

| 用途 | 本地能力 | 云端能力与限制 |
| --- | --- | --- |
| speech 语音 | SenseVoiceSmall q8 + FSMN-VAD，输出转写和语音活动分段时间；不是逐字对齐 | 选定 STT 连接；仅采用提供商实际返回且通过范围校验的分段时间 |
| sound 复杂声音 | 不提供完整环境声理解；语音附带事件标签只作有限预测 | 选定音频理解连接，对片段作文字描述；不是精确事件量测 |
| rhythm 节奏 | 能量起音/自相关估计 BPM 候选，可能半拍/倍拍；无拍号或强拍保证 | 片段描述，不能当作精确 BPM 测量 |
| melody 旋律 | 混合音频的主导周期音高候选；无声部分离，不等于主唱旋律或乐谱 | 片段描述，不能当作逐音符转录 |
| chords 和弦 | 24 个大/小三和弦模板候选；分数不是概率，不识别全部和弦类型 | 片段描述，不能当作准确和弦谱 |
| structure 结构 | 片段内能量/色度变化点；不能据短片段标整首歌的主歌、副歌 | 片段描述，不能证明未提供部分的整曲结构 |

本地音乐分析为有界 TypeScript 算法，不需要 Python、Torch、分离模型或音乐权重。证据不足会明确返回不足；本地语音空结果也不能证明片段没有声音。

## 配置和资源

语音云端连接必须为 `stt` 类型、`openai-compatible` 协议，使用 `/audio/transcriptions`。声音/音乐理解连接必须为 `chat` 或 `custom` 类型、同一协议，并由提供商实际支持当前实现的 Qwen-Omni 兼容 `input_audio` WAV 输入、SSE 与文字输出。选择“兼容协议”或模型名字本身不证明它支持音频。配置只保存连接 ID；凭据仍由宿主管理。云端模式会把所选片段交给该提供商，未配置或不兼容时明确失败，不回退本地。

本地语音当前限定 Windows x64 CPU。固定公开资源共 **260,887,284 字节**（约 248.8 MiB 下载量，另需解压及临时空间），CPU 固定 8 线程，本地任务单次串行。资源版本、实际大小和 SHA-256 固定在 [vendor/sensevoice.json](vendor/sensevoice.json)，没有任意命令、路径或下载 URL 配置。设置页显示就绪状态、下载进度及失败说明；重复准备合并，校验后原子安装，失败可重试。停用取消下载与在途任务。2026-11-08 的授权本机验收中，13.7 秒合成中文语音的解码与本地转写合计约 3.9 秒；有同音字误转，这一单样本不代表任意录音的速度或准确率。

资源直连不可达时，可在“资源下载代理”填入已配置的 HTTP/HTTPS 代理地址（不含用户名密码），保存并重载后再准备。只改变本地资源下载路由，官方地址与摘要校验不变；不修改模型连接或自动直连重试。留空表示直连，Windows 系统代理开关不会自动成为此设置。

视频与音频解码使用插件目录内固定的 FFmpeg/ffprobe 9.0.2，不依赖系统 PATH。源码构建会准备并复制这些组件；已有安装缺失或损坏时，按 [安装说明](vendor/FFMPEG-INSTALL.md) 补齐并重载。启动校验失败时关闭相应解码能力；图片/GIF 不依赖这些程序。设置修改后重载生效，旧容量和有效期保留，旧自定义解码器路径继续忽略。

## 媒体、时间与隐私边界

- 图片支持 JPEG、静态 PNG、WebP、GIF；单图 25 MiB、4000 万像素，动画最多 2000 帧，APNG 拒绝。视频支持有限 MP4/WebM；音频接受经内容核验的 WAV、MP3、FLAC、Ogg、音频 MP4/WebM。
- 视觉仍按 2 fps 低分辨率网格选变化帧与兜底帧，最多 8 帧；支持指定时刻、归一化局部裁剪、独立图片或拼图。概览长边最多 640，细节最多 1600；图片去除 EXIF。采样可能遗漏快速动作，`timelineComplete:false` 不表示完整观看。
- 画面、音频覆盖范围和证据顶层 `segments` 使用源媒体秒数。音乐 `details.timeOrigin:"clip_start"` 内的音符、和弦、变化点等时间，以及云端分析正文中的时间，均以本次片段起点为零；不要再次偏移顶层分段或把内部特征当作源时间。
- 默认单媒体 64 MiB、总暂存 256 MiB，引用 30 分钟有效；每会话最多 16 份、全局 64 份，同时服务调用最多 2 项。引用只对交入时固定的会话有效，重载后不恢复。图像与音频共同读取同一原始暂存媒体；解码片段只短期存在。
- 原始媒体位于插件自己的 `data/media/`；语音资源位于 `data/audio-local/`。正常结束、失败或取消后清理识别片段；启动/准备检查并清理确切自有命名的孤儿片段，不删除未知文件或跟随符号链接。资源模型保留供下次使用。
- 工具资料与后续复制的临时参数按宿主临时工具契约隔离，不把 base64、原声、引用、完整转写写进动作回执。**普通会话的最终回答仍按宿主规则持久化**，其中可能包含模型引用的媒体内容；临时输入不等于最终回答完全不留存。技术性 transient 执行入口另有宿主规则。
- 取消、过期、释放与停用会停止或丢弃在途结果；不会把失败伪装成已理解。声音或画面单项失败可返回明确的部分结果。来源资料是证据，不是指令或操作授权。

本版不直接访问网页、QQ、摄像头或桌面。真实网页视频取得方式及来源插件接入由各自维护方实现；本轮没有修改浏览插件。跨插件方法与具体返回值见 [CONTRACT.md](CONTRACT.md)，公共协作事项见 [CORE-REQUEST.md](CORE-REQUEST.md)。

## 开发、验证和发行

使用 Node.js 24.22.1 或更新版本，宿主源码置于同级 `../whalelife`。生产插件只使用宿主公开 API。构建首次准备固定 FFmpeg 资源，校验后缓存到忽略的 `runtime/` 并复制进发行包；已验证缓存可离线构建。此构建步骤不会准备 SenseVoice 权重。

```sh
npm ci --ignore-scripts
npm run check
npm run build
npm test
```

本轮 0.2.0 自动回归使用合成媒体、模拟资源下载/识别进程、模拟 HTTP/SSE 提供商与隔离宿主子进程。随后按用户授权安装正式实例、下载并校验真实语音资源、执行本地转写及音乐分析；当前 DeepSeek 主模型通过一次 `media_understand` 同时正确识别合成视频的画面短码、颜色顺序和不同的语音短码。正式临时验收入口与媒体已撤销，模型资源保留就绪。真实云端音频提供商、真实网页视频与平台来源接入仍未验收；完整范围及一处受审批阻止而保留的合成测试目录见源码仓库 `VALIDATION.md`。

普通 `npm run build` 只生成本地测试包，并在 `RELEASE-STATUS.json` 标记为未经二进制发布验收。公开含 FFmpeg 的安装包前，必须完成 [源码材料审查](vendor/FFMPEG-SOURCE-REVIEW.md)，执行 `npm run build:release`，上传前再执行 `npm run release:check`。检查仅离线读取资料，不下载、不联系服务；资料不齐时会失败，并保留既有产物。当前固定 Gyan 构建的完整材料仍待取得，不把类型检查或业务测试通过当作发布许可。

发行目录为 `dist/vision/`，包含生产依赖、视频组件、许可与 `BUILD.json` SHA-256 清单，不包含用户数据或本地语音权重。安装目录仍为宿主 `plugins/vision/`，升级保留自己的 data。开发会话只完成本地验证与提交；推送和 Release 交统一发布会话。
