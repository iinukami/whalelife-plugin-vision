# WhaleLife 视觉插件

为当前聊天的同一个主模型准备来自各插件的图片与视频。来源插件负责取媒体，视觉插件负责检查、缩放、裁剪和视频采样，图库负责收藏；不另选视觉模型，不改变 QQ 已有识图。

**0.1.0 提供媒体准备与可选的主模型查看。** 跨插件服务、图片处理、GIF/视频按时间采样与高清补看已实现。宿主提供公开 `ctx.tools.registerMultimodal` 时注册 `vision_view`，把图片字节作为原生视觉内容送入当前主模型；旧宿主明确显示 `multimodal_required`，保留媒体准备与 `vision_status`，不把 base64 当文本代看。所选模型须实际支持图片，插件不自动换模型。

2026-11-05 已在主干确定提交 `39a379962ea5e7c4f641874e052b9f46913db3ba` 上复测通过，并经用户授权安装正式实例。独立测试会话沿用当前 `deepseek-flash`，完成图片概览/局部细节、GIF 指定时刻、视频概览与补看验收；模型正确识别只存在于画面中的随机短码。测试入口和媒体已清理，标准发行包保持启用，日常会话与模型配置未改。QQ、图库等来源插件尚需各自接入。接口依据及接入边界见 [CORE-REQUEST.md](CORE-REQUEST.md)。

## 能力和限制

- 图片：JPEG、静态 PNG、WebP、GIF；单图 25 MiB、4000 万像素；GIF/动画 WebP 最多 2000 帧，按延时选帧，保留收到的原始字节。APNG 明确拒绝。
- 视频：有限 MP4、WebM，需本机 FFmpeg 与 ffprobe，时长最多一小时。默认单媒体 64 MiB、总暂存 256 MiB，可在设置中调整到文档允许的上限。
- 每次查看默认 30 秒、最多 60 秒；在 2 fps 的低分辨率时间网格上，根据画面突变、累计变化和定时兜底选择最多 8 帧。超过数量时按时间分布保留并报告省略数；不承诺无损捕获快速动作或小面积变化。
- 返回每帧采样位置、请求覆盖范围、下一段位置和未包含音频的说明。`timelineComplete` 始终为 false，表示不曾逐帧完整观看。最后一段无 next 不等于此前所有段都看过。
- 指定时刻可准备较高清画面；支持归一化局部裁剪。概览长边最多 640，细节最多 1600；视频裁剪前最多解码到 4096 长边。可选带编号/时间的拼图，默认独立图片以保留细节。返回图片去除 EXIF，最多 8 MiB，不输出媒体路径。
- 引用默认 30 分钟有效，只对交入时固定的会话有效；每会话最多 16 份、全局 64 份，同时处理最多 2 项。取消不会继续返回迟到的图；停用清理本插件媒体，重启不恢复旧引用。清理失败会显示状态并在下次启动重试自己的暂存文件。
- 本版仅处理其他插件交来的媒体字节，不访问网页、摄像头或桌面，不提供声音转写、主动唤醒、收藏或外发。

服务数据和图片正文只供可信插件调用，不可将 `prepare()` 返回值交给普通 JSON 工具结果、日志或长期记忆。接入与示例见 [CONTRACT.md](CONTRACT.md)。

## 开发和构建

使用 Node.js 24.22.1 或更新版本；宿主源码放在同级 `../whalelife`，安装各自开发依赖。生产插件不运行时导入宿主内部模块。FFmpeg、ffprobe 在 PATH 或插件配置中明确提供，不捆绑二进制。

```sh
npm ci --ignore-scripts
npm run check
npm run build
npm test
```

测试使用合成图片、GIF、视频和临时宿主，包含主干 `213b52b` 兼容基线与当前宿主的真实插件子进程。视频测试要求测试机 FFmpeg/ffprobe 可执行；不以跳过视频测试声称通过。测试文件均在项目 `.artifacts/tests/` 下登记并清理，不使用真实账号、模型或用户记忆。

发行目录为 `dist/vision/`，包含当前平台的 sharp 运行依赖、许可证和 BUILD.json SHA-256 清单。需要在目标平台构建；不要把 Windows 依赖包用于其他系统。安装目录为宿主 `plugins/vision/`，升级保留自己的 data。本机正式实例已安装 0.1.0 并启用；其他部署仍需核验宿主与来源插件接入。

插件设置可修改容量、有效期与解码器位置；保存后重载生效，页面保留待重载状态。媒体只存在本插件 `data/media/`，不写账号、会话内容或模型连接配置。
